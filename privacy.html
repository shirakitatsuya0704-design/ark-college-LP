プライバシーポリシー

制定日：2026年11月12日 ／ Ark Growth Partners（屋号：Ark College）

Ark Growth Partners（屋号：Ark College、以下「当社」といいます）は、個人情報の保護に関する法律その他の関連法令を遵守し、当社が提供するサービス（Ark College本体サービス、じぶんラボアプリ、ウェブサイト、問い合わせフォーム等。以下「本サービス」と総称します）における個人情報の取り扱いについて、本プライバシーポリシー（以下「本ポリシー」といいます）を定めます。

第1条（総則）

  1. 当社は、本サービスを通じて取得する個人情報の重要性を認識し、適切な取得、利用および管理に努めます。
  2. 本ポリシーは、本サービスを利用するすべての方（生徒、保護者、問い合わせをされた方、ウェブサイト閲覧者等を含みます）に適用されます。
  3. 本ポリシーにおける「個人情報」「個人データ」「保有個人データ」等の用語は、個人情報の保護に関する法律（以下「個人情報保護法」といいます）に定義されたものと同じ意味で使用します。

第3条（取得する個人情報）

当社は、本サービスの提供にあたり、以下の個人情報を取得することがあります。

3.1 お問い合わせ・入塾申込時に取得する情報

  • 生徒氏名、フリガナ
  • 生年月日、学年、在学校名
  • 連絡先（メールアドレス、電話番号、住所）
  • 保護者氏名、保護者連絡先
  • 志望校、志望動機、現在の学習状況
  • 海外在住の場合：現在地、時差、通学時間等

3.2 サービス提供中に取得する情報

  • 面談・授業記録（ノート、録音、録画）
  • 学習成果物（志望理由書、エッセイ、小論文等のドラフト）
  • 添削記録
  • Slack等のチャット履歴
  • オープンキャンパス参加記録、模試成績等

3.3 じぶんラボアプリで取得する情報

  • ログインID（メールアドレス等）
  • ワークシート回答内容（原体験、価値観、興味、問いのタネ等）
  • 「ふりかえり面談」記録
  • アクセスログ

3.4 支払い時に取得する情報

  • 支払方法、支払履歴
  • 請求書・領収書情報

3.5 ウェブサイト閲覧時に自動取得する情報

  • IPアドレス
  • Cookie情報
  • ブラウザ種別、OS情報
  • 閲覧ページ、滞在時間
  • リファラ情報

第4条（利用目的）

当社は、取得した個人情報を以下の目的で利用します。

  1. お問い合わせへの対応・入塾相談
  2. 本サービス（指導、カリキュラム設計、教材提供、面談、添削等）の提供
  3. 生徒の学習状況の分析・カリキュラムの最適化
  4. 保護者への学習状況の報告・連絡
  5. じぶんラボアプリの運営・改善
  6. 請求・決済処理、契約管理
  7. 本サービスに関する重要なお知らせ・緊急連絡
  8. 本サービスの改善、新サービスの開発
  9. 統計データの作成（個人を特定しない形式）
  10. アンケート、調査への協力依頼
  11. 合格実績の公開（ただし、個人が特定されない形に加工した場合に限る）
  12. 法令遵守および当社の権利・財産の保護
  13. 本人確認、不正利用の防止

第5条（個人情報の第三者提供）

  1. 当社は、以下の場合を除き、あらかじめ本人（未成年者の場合は保護者）の同意を得ることなく、個人情報を第三者に提供しません。
    1. 法令に基づく場合
    2. 人の生命、身体または財産の保護のために必要であり、本人の同意を得ることが困難な場合
    3. 公衆衛生の向上または児童の健全な育成の推進のために特に必要があり、本人の同意を得ることが困難な場合
    4. 国の機関、地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合
    5. 緊急時において、生徒の安全確保のため、保護者、学校、医療機関等に情報提供する場合
  2. 当社は、第三者提供を行った場合、個人情報保護法の定めに従い、提供先、提供日、提供した個人データの項目等を記録し、保存します。

第6条（業務委託）

  1. 当社は、本サービスの提供にあたり、以下の業務を第三者に委託することがあり、その際、業務の遂行に必要な範囲で個人情報を提供します。
    1. サービス運営システム（アプリインフラ、CRM、ファイル管理等）
    2. 決済処理
    3. メール配信、通知サービス
    4. クラウドストレージ、データベース
    5. アクセス解析ツール
    6. 業務用コミュニケーションツール
    7. その他、本サービスの提供に必要な業務
  2. 当社は、委託先との間で個人情報の取り扱いに関する契約を締結し、適切な監督を行います。

第7条（外国にある第三者への提供）

  1. 当社は、本サービスの運営にあたり、外国にある第三者に個人情報を提供する場合があります。
  2. 提供先の国における個人情報保護制度に関する情報は、個人情報保護委員会のウェブサイト（https://www.ppc.go.jp/）でご確認いただけます。
  3. 当社は、外国にある第三者に個人情報を提供するにあたり、個人情報保護法の定めに従い、適切な措置を講じます。

第8条（保有個人データの開示・訂正・利用停止等）

  1. 本人（または法定代理人）は、当社に対し、以下の請求を行うことができます。
    1. 保有個人データの開示請求
    2. 保有個人データの訂正、追加、削除請求
    3. 保有個人データの利用停止、消去、第三者提供停止請求
    4. 第三者提供記録の開示請求
  2. 請求方法：以下の窓口まで、書面またはメールにてお申し出ください。
    tatsuya.shiraki@ark-collegejp.com
  3. 対応期間：請求を受けてから、原則2週間以内に回答します。
  4. 本人確認：不正請求を防ぐため、本人確認書類の提出を求めることがあります。
  5. 手数料：開示請求については、1件につき1,000円の手数料を申し受けます。訂正・削除請求は無料です。

第9条（未成年者の個人情報）

  1. 本サービスの利用者は、主として高校生等の未成年者です。
  2. 未成年者から個人情報を取得する場合、原則として保護者の同意を得たうえで取得します。
  3. 保護者は、未成年者である生徒の保有個人データについて、法定代理人として開示、訂正、削除等の請求を行うことができます。
  4. 生徒が成年に達した場合は、本人の意思を確認したうえで、情報管理方針を見直します。

第10条（生徒と保護者の間の情報共有）

  1. 本サービスでは、生徒本人が講師に共有した情報の一部について、保護者に共有しない運用をとる場合があります。これは、生徒の内省を促し、信頼関係を構築するために必要と考えるためです。

  2. 保護者に共有する情報の範囲（原則）

    • 出席状況、授業内容の概要
    • 学習の進捗状況、ステージ到達状況
    • 志望校の決定状況
    • 課題提出状況

  3. 保護者に共有しない情報の範囲（原則）

    • 生徒が1on1で話した個人的な内省内容
    • 価値観、原体験に関する詳細な記述
    • 家族関係、恋愛、交友関係に関する相談
    • 進路選択に関する葛藤の詳細

  4. 例外（保護者・関係機関への連絡を行う場合）

    • 生徒の生命、身体、健康に重大な危険があると判断される場合
    • 犯罪に巻き込まれる恐れがあると判断される場合
    • 法令に基づく場合
  5. 保護者が法定代理人として生徒の保有個人データの開示を請求した場合、原則として生徒本人の意向を確認したうえで対応します。

第11条（授業・面談の記録）

  1. 当社は、サービス品質向上、指導内容の振り返り、講師間の情報共有のため、以下の記録を行うことがあります。
    1. オンライン授業の録画
    2. 1on1面談の音声録音
    3. 面談記録、チャット履歴の保存
  2. 記録データの利用範囲
    • 当社内部での指導品質管理、講師の指導力向上
    • 生徒本人からの要望があった場合の振り返り提供
    • 第三者への提供は行わない
  3. 保存期間：契約終了から1年間保存し、その後削除します。本人からの申し出があれば即時削除します。

第12条（内省データ・センシティブ情報の取り扱い）

  1. じぶんラボアプリおよび1on1面談等を通じて取得する以下の情報は、当社は特別に慎重に取り扱います。
    • 価値観、人生観、信念に関する情報
    • 原体験に関する情報（家族関係、挫折経験等を含む）
    • 将来の夢、悩み、不安に関する情報
    • 自己分析に基づく自己評価
  2. これらの情報は、原則として本人の同意を得ずに第三者に提供することはありません。
  3. 統計データ、サービス改善、研究等の目的で利用する場合は、必ず匿名化し、個人を特定できない形式に加工します。

第13条（合格実績・体験談の公開）

  1. 当社は、生徒の合格実績、体験談、授業の成果等を、当社ウェブサイト、SNS、広告資料等で公開することがあります。
  2. 公開にあたっては、必ず事前に本人および保護者の同意を得たうえで、原則として個人が特定されない形（イニシャル、仮名、匿名化等）で行います。
  3. 実名・顔写真等の公開を伴う場合は、別途書面による同意を得ます。
  4. 公開後も、本人または保護者からの申し出により、速やかに非公開・削除の対応を行います。

第14条（安全管理措置）

当社は、個人情報の漏洩、滅失、毀損を防止するため、以下の措置を講じます。

組織的安全管理措置

  • 個人情報取扱責任者の設置
  • 個人情報取扱規程の整備
  • 定期的な内部監査

人的安全管理措置

  • 役員・従業員への教育
  • 守秘義務契約の締結

物理的安全管理措置

  • 個人情報を取り扱う領域の施錠、入退室管理
  • 機器・媒体の盗難、紛失防止

技術的安全管理措置

  • アクセス制御、認証管理
  • 通信の暗号化
  • ウイルス対策、不正アクセス対策
  • アクセスログの記録・監視

第15条（Cookie・アクセス解析ツール）

  1. 当社ウェブサイトでは、サービス向上、利便性向上、利用状況の分析のため、Cookieおよび類似の技術を使用しています。
  2. 当社は、アクセス解析ツールおよび広告配信技術を利用して、ウェブサイトの利用状況および広告効果を測定することがあります。
  3. Cookieの受け入れは、ブラウザ設定で拒否することができます。ただし、拒否した場合、本サービスの一部機能が利用できなくなる場合があります。
  4. 広告配信のパーソナライズを無効化する設定は、各種オプトアウトページから行うことができます。

第16条（退会・契約終了後の取り扱い）

  1. 本サービスの契約終了後、取得した個人情報は以下の期間、適切に保管し、その後削除または匿名化します。
    • 契約関連書類：法令に基づく保存期間（原則5年）
    • 学習記録、面談記録：契約終了から1年
    • 支払履歴：会計法令に基づく保存期間（原則7年）
    • その他：契約終了から1年
  2. 本人からの削除請求があった場合、法令で保存が義務付けられているものを除き、速やかに削除します。

第17条（本ポリシーの改定）

  1. 当社は、法令改正、サービス内容の変更等に伴い、本ポリシーを改定することがあります。
  2. 重要な変更がある場合は、当社ウェブサイトに掲載し、または本人に通知します。
  3. 本ポリシーは、当社ウェブサイトに掲載された時点から効力を生じます。
